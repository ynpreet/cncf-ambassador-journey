# CNCF Ambassador — Application Checklist

Target: next application window (annual, expected ~mid-2027). Applicants are evaluated
on **two or more** of the five categories below. Reviewers demand a proof link for
every claim — this checklist is the evidence log.

## 1. CNCF project contribution — THE GAP (per CNCF community team, Oct 2026)
- [ ] First merged PR in a CNCF-hosted project
- [ ] Contributions across 10+ CNCF observability & analysis projects (see CONTRIBUTIONS.md)
- [ ] DevStats contributor score ≥ 20 in at least one project (or voter status, or SIG/TAG membership)
- [ ] Sustained contribution history building toward ~2 years in the ecosystem

## 2. Community leadership (min 1 year, ideally 2)
- [x] Organizer, Boston Databricks User Group
- [x] Runs a ~1,500-member practitioner community (WhatsApp)
- [ ] Join or help run a CNCF Community Group (CNCG) / cloud native meetup chapter
- [ ] CNCF event program committee or KCD organizing (stretch)

## 3. Public speaking
- [x] Panelist, Manning CICS 'Future of Computing' Tech Conference (Apr 2026)
- [x] Speaker, UMass Amherst and Apache Spark NYC meetup
- [ ] Cloud-native topic talk (CNCG / KCD / meetup) with a public recording link

## 4. Mentorship
- [x] Mentors UMass Boston agentic-AI students; 3,000+ students guided overall
- [ ] Mentor in a CNCF-named program (LFX Mentorship / GSoC / Outreachy)

## 5. Content creation (public, not behind paywalls)
- [x] Daily 'Healthcare for Data Engineers' series + articles on datawithpreet.github.io
- [x] ~20.8K LinkedIn followers, regular technical posts
- [ ] Cloud-native content: observability for data pipelines (series/posts with links logged here)
- [ ] Guest post on a CNCF or CNCF-project blog (stretch)

## Program facts
- Application window: annual (~May–July); 2026 window closed Jul 12, 2026; next expected ~mid-2027
- Term: 2 years; past ambassadors must reapply
- Selection: CNCF community team; 2026 had 600+ submissions, 58 new ambassadors accepted
